# VJkit-for-Ableton
This maxpat(m4l) enables to perform music with visual by using MIDI notes

MIDI60 : Zoomer & some visual effect (like pixer)
MIDI61 : some visual effect (like pixer)

only for user who use Ableton Live12 suite or later

Videos
you can upload up to 4movies.


How to Use
1.create a midi track and midi notes
2.insert this device
(i recommend you share DrumRack with this device)
